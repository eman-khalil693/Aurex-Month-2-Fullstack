
# Aurex Month 2 - Task Manager App

## Project Overview
This project is part of the Aurex Full-Stack Engineering Internship Month 2.

## Task 1: React Component-Based UI Development

### Technologies Used
- React
- Vite
- JavaScript
- CSS

### Features
- Add new tasks
- Delete tasks
- Mark tasks as completed
- Search tasks
- Filter tasks
- Display total, active, and completed tasks

## Project Structure
The frontend is organized into reusable React components.
